Llamastat

See what your local AI models are doing, from the menu bar. Live tokens/s, context, RAM, GPU and swap, plus load and eject models without leaving the tray.

Mira qué hacen tus modelos de IA locales desde la barra de menú. Tokens/s en vivo, contexto, RAM, GPU y swap, y carga o expulsa modelos sin salir de la bandeja.

What it shows

Qué muestra

Tokens per second, liveTokens por segundo, en vivo

Generation and prompt-processing speed per model, with history, straight in the menu bar icon.

Velocidad de generación y de procesado del prompt por modelo, con historial, en el propio ícono de la barra.

Context in useContexto en uso

How full each model's context window is and the number of active requests.

Qué tan lleno va el contexto de cada modelo y cuántas peticiones hay activas.

RAM, GPU and swapRAM, GPU y swap

System memory, per-process usage, GPU utilisation and swap pressure, so you know when a model no longer fits.

Memoria del sistema, uso por proceso, utilización de GPU y presión de swap, para saber cuándo un modelo ya no cabe.

Load and eject modelsCargar y expulsar modelos

Pick a preset to load it on the llama.cpp router, or unload what you are not using, from the panel.

Elige un preset para cargarlo en el router de llama.cpp, o descarga lo que no uses, desde el panel.

llama.cpp + Ollama

Full stats with the llama.cpp router. With Ollama: memory, context and when the model will be released (no tokens/s).

Estadísticas completas con el router de llama.cpp. Con Ollama: memoria, contexto y cuándo se libera el modelo (sin tokens/s).

Small and nativePequeño y nativo

Rust core and the system webview (Tauri). No Electron, one code base for the three platforms.

Núcleo en Rust y el webview del sistema (Tauri). Sin Electron, un solo código para las tres plataformas.

macOS
  1. Open the .dmg and drag Llamastat to Applications.
  2. Right-click Llamastat → Open the first time (unsigned build).
  3. It lives in the menu bar; the panel opens from the icon.
  1. Abre el .dmg y arrastra Llamastat a Aplicaciones.
  2. Clic derecho en Llamastat → Abrir la primera vez (build sin firmar).
  3. Vive en la barra de menú; el panel se abre desde el ícono.
Windows

Run the -setup.exe (or the .msi). Needs WebView2, which ships with Windows 10 21H2+ and 11; the installer adds it if missing. The icon sits in the notification area; the tooltip shows tokens/s and the loaded model.

Ejecuta el -setup.exe (o el .msi). Necesita WebView2, que viene con Windows 10 21H2+ y 11; el instalador lo añade si falta. El ícono queda en el área de notificación y el tooltip muestra tokens/s y el modelo cargado.

Set up a backend

Configura un backend

Llamastat reads from servers you already run; it does not run models itself. For full stats, run llama-server in router mode with metrics = 1 in each preset. Ollama works out of the box on its default port.

Llamastat lee de servidores que ya tienes corriendo; no ejecuta modelos. Para las estadísticas completas, corre llama-server en modo router con metrics = 1 en cada preset. Ollama funciona directamente en su puerto por defecto.

The repo ships presets and scripts that install the router as a service on macOS (LaunchAgent), Linux (systemd --user) and Windows (PowerShell): examples/llama-router. Full guide in the README.

El repo trae presets y scripts que instalan el router como servicio en macOS (LaunchAgent), Linux (systemd --user) y Windows (PowerShell): examples/llama-router. Guía completa en el README.
